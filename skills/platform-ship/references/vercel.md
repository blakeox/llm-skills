# Vercel release checks

Use for Next.js, Functions, Edge Middleware, environment variables, build settings, domains, routing, caching, or preview promotion.

## Verify

- Exact team, project, environment, deployment, source revision, artifact, domain, and promotion path
- Node versus Edge runtime, build output, framework settings, environment parity, regions, and function limits
- Middleware, redirects, rewrites, headers, authentication, ISR, image, static, dynamic, and cache behavior
- Preview-to-production differences, traffic cutover, prior deployment restoration, and data compatibility
- Logs, analytics, alarms, feature kill switch, and rollback notification path

Treat missing project, environment, routing, control-plane, or live-runtime evidence as `INDETERMINATE`.
