# UX design output

## User job and evidence

State the user job, success moment, reviewed path, evidence, and missing research or states.

## Findings

Order material friction using the shared finding contract. Include the step, user intent, failure or delay, cause, and smallest correction.

## Proposed flow

Provide the dependency-ordered path, state requirements, information-architecture changes, defaults, recovery behavior, and specific steps or choices to remove.

## Scope

Separate the honest minimum correct flow from the higher-investment experience. State context that could change the recommendation.

## Verdict

- **Ready with cleanup** — the direction is right but friction remains
- **Rethink the flow** — the problem is real but the workflow is wrong
- **Start over** — the experience solves the wrong problem or buries the right one

End with open questions and `What I did not evaluate`.
